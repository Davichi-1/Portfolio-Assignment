Python, AI

Davichi ScanBot, a Telegram image scanner

Problem
Finding out what something is from a photo usually means switching between apps. I wanted that answer inside Telegram, with follow-up questions about the same photo.
Tools
Python, Telegram Bot API, Google Gemini (vision), Docker.
What I did
I built the bot with AI help, set it up with my own Telegram bot token and Google Gemini key, and deployed it on Telegram as @DavichiScannerBot.
What I learned
How a Telegram bot processes incoming photos, interacts with Google Gemini's vision API in Python, and why environment variables are essential for API security.

Real-time audio, deployment

Tactical Walkie-Talkie 2.0

Problem
I wanted phones to work like walkie-talkies: talk to each other in real time over Wi-Fi with no internet, and also online. My first version had trouble connecting devices.
Tools
JavaScript, WebRTC (PeerJS) in version 1, Node.js and WebSocket base server in version 2.0, GitHub Pages, AWS EC2, Caddy, DuckDNS.
What I did
Started from a version generated with Gemini and refined it. Tested it on two devices and kept the working PeerJS version on GitHub Pages. Then built version 2.0 around a WebSocket base server and deployed it on my own AWS EC2 instance behind Caddy, with a free DuckDNS domain.
What I learned
How real-time audio travels between devices, why browsers need HTTPS before they allow the microphone, and how to run a Node.js app on EC2 behind a reverse proxy.

Bash, Linux class lab

Linux server health-check script

Problem
A server can fail quietly. I needed one command that shows whether a Linux machine is healthy.
Tools
Bash, df, free, ps, awk, grep, sed, curl, find.
What I did
Wrote a script that reports the host, uptime and CPU count, warns when the root disk reaches 80%, shows memory and the top three memory-using processes, checks that sshd, docker, nginx and cron are running, and tests outside connectivity with curl. It stops on errors and cleans up with a trap.
What I learned
How to read command output with pipes and awk, loop over services with if/else checks, and make a script fail safely with set -e, pipefail and trap.
